# 文风设计与语言禁忌

本 skill 定义成人色情小说的**文风审美**与**语言硬性禁忌**。适用于多种背景（都市、校园、仙侠、末世、职场、古代等），不绑定具体女主。

## 第一部分：文风设计总纲

### 0.1 ★强制强化六要素（最高优先级，所有H段落必须逐条落实）

**本条款优先级高于本 skill 其余一切规则。** 每一段 H 描写都必须密集覆盖以下六要素，缺一不可；任何"一笔带过""点到为止""省略描写"的写法均视为违规：

1. **身体描写（多）**：乳房（大小/形状/晃动/乳尖状态/乳浪）、腰臀（塌腰/反弓/臀浪/弹颤）、大腿（夹紧/缠腰/绷直/颤抖）、肌肤（泛红/汗湿/冷白/粉嫩）。同一场景至少刻画 3 个身体部位，且随性爱推进更新其状态（充血/红肿/淤痕/抖动）。
2. **淫荡表现（多）**：主动迎凑、主动索求（"射进来""不要停"）、主动指导体位、失神痴态（翻白/吐舌/流涎）、被操到求饶仍贪吃、高潮后立刻索要下一轮。**女主必须表现出享受与贪欲**，用行动与言语双重证明其淫荡，而非被动承受。
3. **体液（多）**：淫水（初渗→滴落→泛滥→喷溅/潮吹）、精液（射精量/温度/流向/体内灌满/外溢/混合白沫）、汗水、泪水、涎水、白沫（撞击产生的细泡）。必须指明**源头→流向→残留物**，且数量随情节递增，终局达到"浸透/灌满/淌地"的饱和态。
4. **性爱动作（多）**：至少 3 种不同的动词变化（挺入/贯入/凿进/研磨/抽送/顶弄），写明**节奏**（浅尝→渐深→大开大合→急速冲刺）、**幅度**（整根/半根/只留龟头）、**体位变化**（至少 1 次切换或位置调整）。
5. **性器（多）**：女性（穴口开合/媚肉缠咬/宫颈被撞/阴蒂肿胀/内壁褶皱/子宫被灌）、男性（龟头/冠状沟/茎身青筋/囊袋拍打/马眼吐精）。写清两者**如何接触**（龟头碾过宫颈、媚肉绞紧冠状沟、茎身刮过内壁褶皱），尺寸与紧致度对比明确。
6. **迎合（多）**：女主身体与言语的双重迎合——内壁主动绞紧/吮吸/蠕动、腰臀主动迎送、双腿主动缠夹、主动摆出姿势、主动说出淫语（"操我""用力""射进来"）。**迎合是女主淫荡本性的直接证据**，必须高频出现，贯穿全程。

**检测标准**：任选一段 100 字正文，应至少包含上述 3 类要素；任选一整场 H（500 字以上），六要素必须全部齐备。若某段只有动作没有体液、或只有呻吟没有身体状态，视为不合格，需回补。

### 0.2 ★细节"三实"标准（0.1 的执行细则，优先级高于本 skill 其余规则）

六要素的每一项描写都必须达到"三实"，禁止模糊概括：

1. **数值实**：性器/体液/体型用量级承载，而非"很大/很多"（"长三十公分、粗如小臂""数以百毫升计的兽精""小腹以肉眼可见的速度鼓胀"）。数字用自然量词表达，避免生硬阿拉伯数字堆砌。
2. **质感实**：写清颜色、纹理、硬度、温度的分层（"紫黑色的粗大青筋与凸起的肉疙瘩""龟头硬如铁锤""滚烫如热铁"）。同一部位至少两个质感维度。
3. **状态实**：实时更新液体与生理的当前状态（"马眼正顺着滴落透明粘稠的前液""穴口无力地翕动""红肿合不拢"）。体液必须有源头→流向→残留的持续追踪，不写一次性状态。

**检测标准**：任一整场 H 场景中，六要素每一项都应能指出其"数值/质感/状态"的具体落点。若某处只写了"很大很粗很多"而没有承载物，视为不合格，需回补。

### 1.1 白描式叙述

叙事以客观、细腻的"白描"为主，用可见的身体信号替代抽象的内心陈述。动作质感强，画面感优先。读者应能"看见"每一帧画面，而非被告知感受。

| 弱句（陈述/抽象） | 强句（白描/展示） |
|------------------|------------------|
| 她感到兴奋 | 乳尖隔着薄薄布料顶出两个清晰的凸点 |
| 她羞耻极了 | 她的脸红透了，但阴道深处却痉挛般收缩，淫水不受控制地涌出来 |
| 她放弃了抵抗 | 她紧绷的腰肢忽然瘫软下来，双腿不再踢蹬，反而缠上了他的腰 |
| 他控制不住了 | 他低吼一声，双手扣紧她胯骨，挺腰猛然整根没入 |
| 她很疼 | 她的十指抠进石缝里，指甲崩断半截，后槽牙咬得格格作响 |
| 她很快乐 | 她的瞳孔放大失焦，舌尖无意识地探出嘴角，涎水拉成银丝 |

**严禁在章节结尾出现"上帝视角"式的总结、抒情或点题旁白。** 高潮与结局一律停留在角色身体状态与场景画面本身。

### 1.2 双重面具与极致反差（核心审美）

女主通常表现为**高冷/端庄/清高**的表面形象（校花、女神、御姐、教师、千金、圣女、仙尊），但内心极度淫荡，表现为**主动享受与沉溺快感**。

- 公众形象的高不可攀是"面具"，私密空间的沉沦是"本相"。
- 反差是情欲的核心张力来源：公众目光下的圣洁 ↔ 私密空间里的放荡；衣冠楚楚的端庄 ↔ 身体的本能反应。
- 通过对比段落实现反差：白天如何被仰望（细节）→ 暗夜如何被使用（细节）。
- 角色在沉沦过程中必须体现**主动迎合、主动索求、主动榨取**，严禁将其描写为"冷漠工具"或"麻木死鱼"。
- 反差类型可叠加：身份反差、冷热反差（冰酒/温泉）、前后反差（公开端庄↔私下浪荡，但**内心始终享受、无道德纠结**）、主动被动反差。
- **空间反差**：让神圣/体面之地的最深处（神殿地牢、祭坛密室、圣所、修道院禁室）沦为兽欲之地，环境本身承担身份剥夺——"圣女被关在自家神殿的地牢里被兽人奸淫"远比外部营地更具亵渎冲击。环境道具（铁栏、锁链、圣油、圣物、祭坛）要实际进入场景参与调教，不能只做背景板。

### 1.3 身体感官优先，心理描写精简

- **严格执行 0.1 强制强化六要素**：身体、淫荡表现、体液、性爱动作、性器、迎合六类描写必须密集铺陈（详见 0.1）。
- 大量描写：身体状态、肉体姿势、器官形变、体液流动、生理反馈。
- **大幅减少心理描写**。心理部分用短促内心独白或括号标注（ ），占比不超过全文 15%。
- 用身体反应替代心理分析（"阴道痉挛"代"她感到羞耻"）。
- 心理描写的作用是标记防线变化，不是解释感受。

### 1.4 体液即叙事

淫液、精液、汗水、泪水——四种体液贯穿场景始终：

- 指明源头（从哪流出）
- 追踪流向（顺着什么淌到哪）
- 标记残留（在什么材质上留下什么痕迹）

**体液累积效应**：开场第一滴淫水 → 中段精液出现 → 后期精液灌满溢出 → 终局全身浸泡精液。逐级叠加，形成叙事进度与堕落程度刻度。

**饱和终局三层标准**（终局必须到达，缺一视为"收着写"）：

1. **鼓起**：小腹因内射明显隆起——"小腹以肉眼可见的速度圆润鼓胀""凸起如同怀孕数月般的圆润弧度"。
2. **洞开**：拔出后穴口无法闭合、无力翕动——"红肿合不拢的穴口""穴口无力地翕动着"。
3. **积池**：体液在身下积聚成可观规模——"积聚成一片粘稠的白浊小池""精液如泉水般喷涌而出，顺着双腿淌下"。

量级可上探极限：射精量以"数百毫升计"、灌满级别用"怀孕数月""装满了子宫还在外溢"承载。宁可"超标"，不可"足量即止"。

### 1.5 敏感度阶梯（身体反应递增）

身体反应必须有递增曲线，不可跳过中间步骤直接高潮：

```
乳头挺立 → 大腿并紧 → 淫液渗出 → 穴口翕动 → 无法自控的痉挛 → 潮吹/高潮
```

每个 H 场景至少完成一次完整阶梯。多轮交合中，每轮敏感度阈值应递减（越来越容易高潮），体现身体被逐步开发。

### 1.5.1 插入深度极限层级（五步阶梯之上的破坏感递进）

首次插入的深度与破坏感按层级推进，级别越高冲击越强：

1. **撞上宫颈**：龟头触及宫颈口，媚肉痉挛咬紧。
2. **碾过宫颈**：反复顶撞，宫颈发红发胀，女主持续失神。
3. **撞开宫口**：龟头楔入子宫口，宫口被撬开一条缝，花汁开始涌出。
4. **顶入子宫腔**：龟头没入子宫内壁，小腹能摸到顶撞的轮廓，潮吹被直接诱发。

人类性器通常在 1-2 级反复；**异种/兽人/魔物或开发充分的场景直接上探 3-4 级**。每升一级，女主的生理反应（痉挛→失神→潮吹）与体液量（白沫→涌出→灌满）必须同步递进。

### 1.6 有限视角与感官锚定

- 始终附着于一个角色的感官：触觉、声音、气味、身体内部感觉。
- 尽量不写对方在想什么。
- 视角切换规则：每次视角切换伴随段落转换或场景转换；禁止在同一段内跳跃视角。
- 窥视/录像/监控是自然的视角切换工具（旁观者视角→当事人视角）。

### 1.7 背景适配微调

| 背景 | 文风微调 |
|------|---------|
| 现代都市/职场 | 强调身份阶层（金主/上司/下属）、场所细节（酒店/会所/办公室）、物品质感 |
| 校园 | 强调青春肉体、纪律与身份落差（师生/学长）、场所（教室/宿舍/实验室/澡堂） |
| 仙侠/古代 | 采用古典词汇（玉户/桃源/阳根/巨根）、仙凡身份落差、药效/灵力设定 |
| 末世/奇幻 | 强调生存胁迫、兽性本能、异种肉体与催情体液设定 |

## 第二部分：语言禁忌与标点规范（强制执行）

### 2.1 禁用词汇表

以下词汇**一律禁止**出现在正文中：

| 类别 | 禁用词 |
|------|--------|
| 程度副词 | 极其（任何语境） |
| 动漫/网文夸张词 | 物理暴击、冲向天灵盖、凄厉嘶吼、撕心裂肺、惨无人道、生不如死、核弹般、爆炸性（夸张用法）、电光石火 |
| 不适配词汇 | 疯狂（感官语境）、咆哮（感官语境）、嘶吼（感官语境）、绝望（感官语境）、机械般（用于人时） |

**注意**："疯狂"仅在极少数非感官语境（如"疯狂按动快门"的围观动作）中可保留，感官描写一律禁用。拿不准时直接替换。

### 2.2 替换表

| 禁用词 | 替换为 |
|--------|--------|
| 绝望 | 迷离 / 沉沦 / 涣散 |
| 疯狂 | 放荡 / 剧烈 / 失控 / 贪婪 |
| 咆哮 | 娇喘 / 闷哼 / 低吟 |
| 凄厉嘶吼 | 变调的娇喘 / 压抑的悲鸣 |
| 撕心裂肺 | 压抑到极点的哭腔 |
| 冲向天灵盖 | 沿脊椎炸开 / 窜上后脑 |
| 生不如死 | 快要坏掉 / 意识涣散 |
| 极其 | 极为 / 格外 / 相当（或直接删去，用描写替代） |

### 2.3 标点与格式规范

| 项目 | 规范 |
|------|------|
| 对话引号 | 必须使用标准中文双引号（" "），禁止英文直引号或单引号 |
| 内心独白 | 使用（ ）括号标注 |
| 省略号 | 使用规范的"……"（六个点，不用"…"或"."） |
| 破折号 | **仅限两种用途**：A. 拟声词后缀（"噗呲——"）；B. 对话中的语气停顿（"你——你怎么会在这里"）。禁止用于：动作→结果连接、角色介绍、背景补充、因果说明（改用句号断开为独立短句） |
| 场景切换 | **禁止使用分割线（---）**。场景切换靠自然段落过渡或视角切换词（"而在另一边""沙发上""窗前"） |
| 感叹号 | 不可滥用，高潮处节制使用，一句内不多于一个 |
| 数字与量词 | 拟声词后接数量词需自然（"灌了两百毫升"而非"灌入200ml"），正文避免生硬的阿拉伯数字堆砌 |

### 2.4 篇幅偏好

- 单章追求超长（8000-15000字以上），通常分段生成后合并，合并时去除中间过渡标题以确保行文流畅。
- 番外/短章按用户指定字数执行。
- 段落长度：慢速描写用长句长段，快速冲刺用短句短段；全文避免清一色等长段落。
