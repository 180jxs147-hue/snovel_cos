# 章节结构、节奏与自查

本 skill 提供成人色情小说的**章级编排方法**：从大纲设计到成品校验的完整闭环。适用于多种背景。

---

## 第一部分：章节五段结构

标准 H 章节按以下五段推进（每段长度按情节需要分配，不必等分）：

1. **开场**：五感建立空间感（至少3感）→ 女主当前穿着/状态 → 场景过渡自然（日常→H）。
2. **前戏**：肢体接触逐步升级（非敏感带→敏感带）→ "嘴上不要身体诚实"反差 → 第一次体液出现。
3. **核心交合**：插入阶梯推进 → 拟声词与动作交替 → 至少2-3种植入动词变化 → 身体部位局部特写。
4. **高潮**：女性高潮完整生理描写（痉挛→潮吹→失神）→ 男性射精明确（量/温度/位置）→ 精液溢出画面。
5. **余韵**：残精流出/穴口状态 → 身体瘫软/意识涣散 → 下一轮或下一个人预设（保持张力）。

**心理线贯穿**：本章女主的享受程度如何递进（初尝→渴求→沉迷→餍足→贪求）？有内心独白标记当前的享受程度？女主是否全程主动索取、主动沉溺？禁止出现"道德抗拒→矛盾→崩溃"的纠结式心理线。

## 第二部分：节奏控制

### 2.1 慢快切换

| 场景类型 | 句式 | 效果 |
|---------|------|------|
| 脱衣/前戏/慢速插入 | 长句分层展开 | 拉长感官、逐寸"看"清 |
| 冲刺/高潮/群交轮换 | 短句+拟声词密集 | 模拟频率、制造压迫 |
| 场景切换/路途过渡 | 中速叙述句 | 缓冲，防止连续高密度疲劳 |

### 2.2 体液累积节奏

- 开场：淫水初现（湿度开始）。
- 前中段：淫水泛滥、白沫产生。
- 中后段：第一次内射、精液混合。
- 后段：精液满溢、顺腿流出、小腹隆起。
- 终局：精液浸泡、浑身精斑、穴口无法闭合。

**注意**：体液累积必须与心理线同步推进——体液越多，堕落越深，两者互为刻度。

### 2.3 敏感度曲线规划

- 多轮交合时，每轮高潮阈值递减（第一轮耗时最长，后面越来越快）。
- 高潮之间必须有"余韵缓冲段"（瘫软、喘息、残精流出），不能无间隔连续高潮。

## 第三部分：章节衔接

- **段间连续**：分段生成时，段末留下情节钩子，合并后无接缝感。
- **场景过渡词**："而在另一边""与此同时""大约半小时后""当……时"——禁止分割线。
- **章末处理**：禁止上帝视角总结/抒情/点题旁白。章末停留在画面（身体的残精、瘫软、下一轮逼近的脚步声），或一句角色自己的话语/独白收束。

## 第四部分：大纲设计模板

### 4.1 场景卡（每个 H 场景一张）

```
场景：<地点+氛围五感>
体位/动作：<主体位→变化→终局体位>
施暴者：<人物A（体型/性器/操法）>、<人物B……>
道具：<口球/眼罩/震动棒/挂牌……>
体液目标：<初潮→精液量→满溢程度>
心理线：<本章享受程度从__递进到__（初尝→渴求→沉迷→餍足→贪求），全程主动沉溺、无道德纠结>
```

### 4.2 章节卡（整章编排）

```
章名：<可含隐喻>
时间线：<开始时间→结束时间>
五段分配：开场__字 / 前戏__字 / 交合__字 / 高潮__字 / 余韵__字
场景清单：<场景1>→<场景2>→<场景3>
新要素：<新角色/新道具/新场所/新体位>
结尾钩子：<下一章悬念>
```

## 第五部分：写作自查清单（每章完成后逐项核对）

- [ ] 是否使用了禁用词汇（极其/疯狂/绝望/咆哮/凄厉嘶吼/物理暴击/冲向天灵盖/撕心裂肺）？
- [ ] 所有对话是否使用中文双引号？
- [ ] 破折号是否仅用于拟声词后缀和对话语气停顿？
- [ ] 是否使用了分割线（---）切场景？
- [ ] 是否出现上帝视角的章末总结/抒情/点题旁白？
- [ ] 女主是否表现出主动享受与沉沦（而非麻木死鱼）？
- [ ] **六要素是否全部齐备**（身体/淫荡表现/体液/性爱动作/性器/迎合）？每 100 字是否含至少 3 类？
- [ ] 每个 H 场景是否完成敏感度递增阶梯？
- [ ] 体液描写是否贯穿始终（源头→流向→残留）？累积是否与心理线同步？
- [ ] 内心独白占比是否超过 15%？
- [ ] 拟声词是否与动作描写交替？同一拟声词是否重复超过3次？
- [ ] 插入是否遵循阶梯推进（对准→进入→整根→抽送）？
- [ ] 是否有至少 2 种反差（身份/冷热/前后/主动被动）？
- [ ] 多人场景中不同男性是否差异化？女性心理模式是否至少2种？
- [ ] 多轮交合时高潮阈值是否递减？高潮间是否有余韵缓冲？
- [ ] 章节篇幅是否符合用户指定要求（正文常规8000-15000字）？
- [ ] 六要素每项是否有"数值/质感/状态"的具体落点（细节三实）？
- [ ] 插入深度是否到达对应层级的极限（撞宫颈→碾过→宫口→子宫腔）？异种/兽人场景是否上探 3-4 级？
- [ ] 终局是否到达饱和三层（小腹鼓起/穴口洞开/体液积池）？
- [ ] 环境是否承担身份反差（神圣/体面之地沦为兽欲之地）？
- [ ] 淫语是否至少到达"粗俗直呼"层？异种场景是否有参照系对比？
- [ ] 束缚场景是否写出"无力承受∩主动迎合"的双重反差？
