# 项目级写作规则 (Project-Scoped Rules)

本文件定义了当前工作区下所有小说创作与修改任务的硬性全局规范。

## 核心要求

1. **技能强行绑定与调用**：
   在进行任何章节续写、大纲设计、润色修改或细节填充时，AI 助手**必须主动读取并严格执行**以下两个 Skill 中的所有规则指南：
   *   [adult-novel-sex-scene-writing (性爱描写微观写作)](file:///e:/SNOVEL/COS/.trae/skills/adult-novel-sex-scene-writing/SKILL.md)
   *   [human-like-webnovel-writing (去AI味网文创作指南)](file:///e:/SNOVEL/COS/.trae/skills/human-like-webnovel-writing/SKILL.md)

2. **去AI味红线自检**：
   在输出内容前，AI 必须严格执行以下红线自检：
   *   **严禁任何比喻词**：全文段落中不能含有 `像`、`仿佛`、`宛如`、`犹如` 等词。
   *   **破折号专项检查**：全文 `——` 字符只允许用于拟声词尾和对话语气停顿，严禁用于因果、解释、动作结果连接。
   *   **单句段合并**：任何日常与H细节描写段落必须多句成段，合并括号内内心独白，严禁单句成段。
   *   **感官与心理双重张力**：强化陈瑶“主动配合/内心暗爽”与“口头/外表惊恐扮演”的反差对比。
